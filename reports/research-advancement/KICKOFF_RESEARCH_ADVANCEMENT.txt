MISSION

Keep the original project: a world model predicts what a diagnostic test would reveal, and the
agent uses imagined outcomes before ordering real tests. Version 3.1 has one pre-registered
contribution. An agent that plans with imagined results should conserve expected evidence: its
reactions to the results it imagines must average to what it believes now. Build the instrument
that measures violations without labels; the projection that corrects drift; the separately named
scale component that matches a test's information budget; the coherent value of information and
commit rule that follow; and the regime map that shows where language-model readers, published
recipes, and the trained clinical agent sit. Validate with exact counterfactual regret in the
synthetic environment, on public complete-record data, and on MIMIC with several trained policies.

Do not substitute a larger-backbone project, an unrelated benchmark, an infrastructure rewrite, or
an open-ended method search. Do not require positive results, forecast an accuracy gain, or promise
acceptance anywhere. Compute does not shape the science: never shrink, skip, or weaken an
experiment to save GPU time or to make a date. The projection repairs drift only and is expected
to hurt readers whose reactions have the wrong scale; the scale component is only as good as its
budget and is harmful when the budget is too large. Report both wherever they appear.

THE METHOD IN BRIEF (the specification's section 5 is authoritative)

Reader: any procedure that maps a history to a probability vector over the diseases. World model:
a distribution over a test's outcomes, including UNAVAILABLE, given the history. For a candidate
test, let b be the reader's belief now, q_o its belief after imagined outcome o, and P_hat(o) the
world model's weight on o.

- Audit: imagined mean b_bar = sum_o P_hat(o) q_o; drift = b_bar − b; responsiveness = expected KL
  of q_o from b_bar. Also measure the reader's reaction to UNAVAILABLE and to an exact re-exposure
  of evidence it has already seen. Both should be zero.
- Projection (CEE-Read): find positive class weights u so that the reweighted posteriors
  u × q_o / Z_o average to b under P_hat, by iterative proportional fitting. Apply the same u to
  the real result. Incoherence KL_inc = sum_y b(y) log u(y) − sum_o P_hat(o) log Z_o.
- Identity: expected log-score gain = KL_inc + sum_y (b_star − b)(y) log u(y)
  − sum_o (P_star − P_hat)(o) log Z_o. The per-case realized gain log u(y_true) − log Z_real is
  observable from factual outcomes.
- Scale (CEE-Scale): temper the reader's increments by 1/tau, project, and choose tau so the
  projected pair carries exactly the test's information budget B. Report tau_B always. Apply the
  repair only where the budget passed its eligibility test and the gate allows it.
- Coherent value of information is computed from the repaired posteriors and is never negative.
  Commit when no eligible test has positive net value. Gate each repair by test type using
  quantities fitted on folds that exclude the scored case.

NONNEGOTIABLE SCIENTIFIC CHECKS

Establish failing tests or hand-computable references first. Use independent mathematical
expectations, not a second helper with the same error.

Name every quantity honestly: location incoherence, budget-implied scale, responsiveness, realized
gain, coherent value of information, entropy-change surrogate. The legacy content score is an
entropy-change surrogate under an incoherent pair; never call it mutual information.

Never choose a scale by minimizing incoherence: an agent that never updates is coherent. Never use
a budget that failed its eligibility test. Never treat coherence as correctness, lower log loss as
higher accuracy, a single-step guarantee as a sequential one, or more confidence as more truth.
Report log loss, accuracy, T5, cost, requests, and runtime together.

Imagined outcomes are predictions. Never write them into a real history, never score them as
observed truth, and never fill unknown chart outcomes with samples. The retrieval world model reads
the training split only and never returns rows from the evaluated admission. A fold policy never
scores an admission it trained on. Test rows are never used for fitting, retrieval, calibration,
budgets, or thresholds.

Every fitted quantity that touches labels outside the training split is cross-fitted by admission.
The unit of analysis is the admission or the patient; orders, prefixes, renderings, and items are
not independent people. One uncorrected primary contrast per experiment; the rest in named Holm
families. A minimum detectable effect is never an equivalence margin.

V1, the hypothesis fallback at T5 84.45 on test, is the reference to beat, not the 73.09
replication; every policy is compared with its own V1. Exact references in the twin obey the same
observation access and budget as the agent. Choose the track, the scale variant, and every
