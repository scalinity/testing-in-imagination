## Backbone adaptation, decided before any run

The replication hard-codes Nemotron in places that are not hyperparameters. Each is handled in the
study's adapter, never by editing the replication:
1. Model allowlist and pinned loaders: extended to the Granite name and revision for E9 only.
2. Nemotron's reasoning switch, the system message "detailed thinking off", is not sent to Granite.
   Granite's chat template is applied with its reasoning mode off and with a fixed system message
   so that no date-dependent default system prompt enters the prompt.
3. Tokenizer-dependent stripping of "Observation:" and pad/EOS handling: unit-checked on the Granite
   tokenizer before training.
4. Weight synchronization into vLLM (tied embeddings, strict name matching): checked in the bench.

## Bench and repairs

A bench of at most 3 GPU-hours first: a short training run and a few validation episodes, checking
format adherence (Thought / Action / Action Input, Hypothesis, Confidence), the four checks above,
and memory. At most two recipe repairs in all, for template or memory faults only, each recorded
on this card with its reason before the next run. If Granite still does not train, that is the
result: reported, and the study continues without cohort B.

## Runs and measurements

warning; each policy's unguarded validation rollout with full prompt logging; its V0 and V1; probe
conformance before any E4 use.
