\begin{abstract}
\noindent
We extend LA-CDM from retrospective, model-free test selection to world-model--based \emph{testing in imagination}: an agent that can evaluate counterfactual diagnostic actions via a learned transition model \(p_\phi(o_{t+1}\mid h_t,a_t)\). This milestone summarizes problem framing, baseline archaeology, HiPerGator-compliant model choices, Stage~1 synthetic environment scaffolding, and next deliverables. Full MIMIC Table~1 reproduction is deferred until PhysioNet access and CUDA jobs are available; we log honest gaps rather than invent metrics.
\end{abstract}

\section{Project goal}

Language agents for clinical decision-making (CDM) typically either assume all patient information is available up front or interact with a retrospective chart where many tests were never ordered. LA-CDM trains a LoRA-adapted language agent with GRPO to iteratively request tests and diagnose under cost pressure, but it remains \emph{model-free}: when a test is unavailable in the chart, the environment returns ``unavailable,'' which is \textbf{not} a counterfactual of what that test would have shown.

Our research question is whether a learned world model \(p_\phi(o_{t+1}\mid h_t,a_t)\) enables planners to \emph{test in imagination}---and whether a flawed world model can make planning \emph{worse} than model-free baselines (a publishable negative result). We compare model-free LA-CDM-style agents, world-model planners, and an oracle world model (available only in synthetic or imputed settings).

\section{Baseline: LA-CDM (reproduce carefully)}

\textbf{Paper:} Bani-Harouni et al., \emph{Language Agents for Hypothesis-driven Clinical Decision Making with Reinforcement Learning}, ICLR 2026 (arXiv:2506.13474).\\
\textbf{Code:} \url{https://github.com/dharouni/LA-CDM}.

Upstream method (shared LLM weights):
\begin{itemize}
  \item \textbf{Hypothesis agent} \(\mathcal{H}: p_j \mapsto \{h_j,c_j\}\) (diagnosis hypothesis + confidence 0--10).
  \item \textbf{Decision agent} \(\mathcal{D}\) (ReAct) that orders a test or commits a diagnosis.
  \item Cyclic training: action GRPO \(\rightarrow\) hypothesis SFT \(\rightarrow\) confidence GRPO; LoRA on an \(\sim\)7--8B instruct backbone.
\end{itemize}

Headline paper claims (Table~1) we will only fill from logged runs: mean Acc \(81.3\), Micro F1 \(84.1\), Macro F1 \(81.3\), avg test cost \(\$1295.61\). We treat GitHub clone \(\neq\) reproduced until config, seed, and metric artifacts are logged (\texttt{REPRODUCTION.md}).

\paragraph{Thesis implication.}
The baseline environment makes unavailability cheap and uninformative. A world model changes the economics so every planned action yields a predicted observation---including counterfactuals the chart never recorded.

\section{HiPerGator constraint and backbone choice}

UF countries-of-concern guidance prohibits PRC-origin LLMs on HiPerGator (Qwen, DeepSeek, Yi, InternLM, and derivatives), even via LoRA or ``re-releases.'' Upstream LA-CDM defaults to \texttt{Qwen/Qwen2.5-7B-Instruct}, so bit-for-bit weight match to their Table~1 setup is not feasible on the cluster.

\paragraph{Our default (logged as D-5).}
\begin{itemize}
  \item \textbf{Policy + HPI summarizer:} \texttt{nvidia/Llama-3.1-Nemotron-Nano-8B-v1}\\
  Meta Llama~3.1 8B Instruct \textbf{US base} + NVIDIA post-training (reasoning / tool-calling). UFIT RC confirmed NVIDIA models are allowed when the base is US.
  \item \textbf{Fallback ablation:} \texttt{meta-llama/Llama-3.1-8B-Instruct} (same family, no Nemotron post-train).
  \item \textbf{World model \(p_\phi\):} tiny bag-of-words / small classifier first---not another frontier LLM.
\end{itemize}

This is a documented reproduction deviation. We do not claim Table~1 bit-for-bit weight match. Hydra/\texttt{prepare\_data} defaults that still point at Qwen must be overridden before any GRPO or vLLM job; HF revision / RC mirror path will be pinned when cluster access is confirmed.

\section{Stage 1 progress (implementation)}

\subsection{Documentation \& research process}
\begin{itemize}
  \item Standing constitution (\texttt{ONBOARDING.md}), claims ledger (\texttt{REPRODUCTION.md}), paper notes, env/tuple specs, open questions.
  \item Formalized POMDP-style interface: history \(h_t\), actions \(\mathcal{A}_{\mathrm{test}}\cup\mathcal{A}_{\mathrm{diag}}\), observation \(o_{t+1}\), objective \(p_\phi(o_{t+1}\mid h_t,a_t)\).
\end{itemize}

\subsection{Synthetic CDM environment (scaffolded)}
Under \texttt{extension/envs/synthetic\_diagnosis/} (no MIMIC/PHI; pure Python + pytest):
\begin{itemize}
  \item Latent disease \(y\) over \(\{\)appendicitis, cholecystitis, diverticulitis, pancreatitis\(\}\).
  \item Twelve LA-CDM-aligned test actions with template observations \(g_a(y,\epsilon)\).
  \item Always-available v0 (no \texttt{UNAVAILABLE}) for clean world-model tuple collection; \texttt{oracle\_observe} for counterfactual probes.
  \item JSONL tuple export CLI (\texttt{collect.py}): random / expert stub policies; diagnosis steps filtered out of WM training tuples.
  \item Unit tests under \texttt{extension/tests}.
\end{itemize}

\subsection{What we deliberately deferred}
\begin{itemize}
  \item Full PhysioNet / MIMIC-IV-Ext-CDM prep and Table~1 GRPO runs (awaiting credentials + HiPerGator GPU).
  \item Treating AnyJev/Jev (typed calibrated decisions) as a new research question---useful as optional decision plumbing later, but would dilute Stage~1's world-model claim.
\end{itemize}
